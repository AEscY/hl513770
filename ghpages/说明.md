> 你这个思路是对的，而且是**目前最接近真 App 的方案**。
> GitHub Pages 是 HTTPS —— 正好绕开 iOS「必须 https 才能添加到主屏幕」的限制。

---

## 为什么这条路能成

iOS 有一条硬规定：**本地文件不能添加到主屏幕，必须是 https 网址**。

GitHub Pages 免费提供 `https://xxx.github.io`，于是：

```
代码托管到 GitHub  →  得到 HTTPS 网址
        ↓
Safari 打开该网址
        ↓
分享 → 添加到主屏幕
        ↓
桌面出现红绿灯图标，点开全屏、无地址栏 ✅
```

**不需要越狱、不需要 Mac、不需要签名。**

---

## 第一步：建仓库（全程手机 Safari 也能做）

1. 浏览器打开 **github.com** → 登录（没有就注册，免费）
2. 右上角 `+` → **New repository**
3. Repository name 填：`hl513770`
4. 选 **Public**（必须公开，Pages 免费版才可用）
5. 勾选 **Add a README file**
6. 点 **Create repository**

---

## 第二步：上传文件

在仓库页面点 **Add file → Upload files**，
把下面 **5 个文件全部拖进去**：

| 文件 | 说明 |
|---|---|
| `index.html` | 主页面（含图表，45KB） |
| `manifest.webmanifest` | PWA 配置 |
| `sw.js` | 离线缓存 |
| `icon-180.png` | iOS 桌面图标（**不透明背景**） |
| `icon-192.png` | Android/通用图标 |
| `icon-512.png` | 大图标 |

拉到底部点 **Commit changes**。

> ⚠️ 图标我已经处理成**不透明背景**。
> Safari 的 apple-touch-icon 要求 PNG 无 Alpha 通道，
> 带透明通道的图会被它压成黑底，很难看。

---

## 第三步：开启 GitHub Pages

1. 仓库页面点 **Settings**
2. 左侧菜单 **Pages**
3. Source 选 **Deploy from a branch**
4. Branch 选 **main**，文件夹选 **/ (root)**
5. 点 **Save**

等 1–2 分钟，页面顶部会出现你的网址：

```
https://你的用户名.github.io/hl513770/
```

---

## 第四步：装到桌面

1. iPhone 用 **Safari** 打开上面那个网址
   （⚠️ 必须是 Safari，Chrome 不行）
2. 点底部 **分享**按钮（方框向上箭头）
3. 下滑找到 **「添加到主屏幕」**
4. 名称改成 **红绿灯**，点 **添加**

桌面出现图标，点开**全屏、无地址栏**，和 App 一样。

## 几个要说清楚的点

**① 全屏效果依赖 `apple-mobile-web-app-capable`**
这个 meta 我已经写进去了。iOS 上它优先于 manifest 的 `display`。
极少数情况下 Safari 会降级成带地址栏模式 —— 如果遇到了告诉我。

**② 离线能力不保证**
Service Worker 在 iOS Safari 上的缓存策略受限（苹果对 `waitUntil`
生命周期和 Cache API 有额外限制）。**别指望完全离线**，当在线工具用。

**③ 数据是内嵌的**
基准是 2026-09-24 收盘 0.333。要更新就得改 `index.html` 里的行情数组，
重新上传。平时不用改 —— 每天 15:30 我会推灯色给你。

---

## 更新数据怎么办

在 GitHub 仓库里打开 `index.html` → 点右上角**铅笔图标**编辑 →
找到 `const R = {...}` 那一大段 → 替换成新数据 → **Commit changes**。

Pages 会在 1–2 分钟内自动生效，桌面图标不用重装。
